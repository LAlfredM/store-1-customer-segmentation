# Segmentación de clientes y análisis de ventas — Store 1

## Descripción del proyecto

Este proyecto consiste en analizar la información de los clientes de Store 1 utilizando Python.

El objetivo es limpiar y organizar los datos de los usuarios para posteriormente identificar patrones de compra, calcular ingresos y segmentar clientes según sus características y preferencias.

## Objetivos

- Limpiar y transformar los registros de clientes.
- Normalizar nombres y categorías de compra.
- Calcular los ingresos totales.
- Identificar clientes menores de 30 años.
- Encontrar clientes jóvenes con un gasto superior a 1000.
- Filtrar clientes según sus categorías de compra.

## Herramientas utilizadas

- Python
- Jupyter Notebook

## Conceptos de programación aplicados

- Listas y listas anidadas.
- Variables y tipos de datos.
- Ciclos `for`.
- Condicionales `if`.
- Funciones.
- Manipulación y limpieza de datos.

## Contenido del repositorio

- `notebooks/`: contiene el notebook con el desarrollo del proyecto y los ejercicios realizados.

## Conclusión

Este proyecto permitió practicar los fundamentos de Python aplicados a la limpieza, organización y análisis de información de clientes, así como la creación de funciones para automatizar tareas y obtener información útil para la segmentación de usuarios.
